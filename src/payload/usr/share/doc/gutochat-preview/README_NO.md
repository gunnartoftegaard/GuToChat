# GuToChat – norsk

GuToChat har rollene Base og Field. Grunnprogrammet krever ingen radio; en
radiomeldingsvei krever en valgt og konfigurert adapter.

Gjeldende kildekladd er kandidat 18docs1 med driver 4. Kandidat18 er ikke installert
eller offentlig publisert. Sist fysisk prøvde testutgave er 17sync1 på Raspberry
Pi 5, Debian 13 aarch64 og Python 3.13. Se versjonsnotatene for nøyaktig bevisgrunnlag.

src inneholder eksakte kandidat 18-prosjektfiler med manifest. Veiledningene er
samordnet med dokumentene i program­pakken. Begge rollers gamle posisjonshistorikk
oppgraderes additivt; driveren og øvrig programlogikk er uendret fra 17.
Eldre APRS-iGate-køer har et separat urettet migrasjonsproblem og har ikke
godkjent oppgraderingsstøtte her. Kodegjennomgang, åpne driftskrav og konkret
publiseringsbeslutning gjenstår. Alle 35 planspor og historiske rettelser beholdes.
